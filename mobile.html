MOBILE LEARNING & INTERACTIVITY

Mobile App Development

DESIGN • CONNECT • ENGAGE

This section showcases my exploration of mobile app development with an optional project created with MIT App Inventor, a cloud based mobile application development platform. I wanted to learn the fundamentals of mobile app development and with this project I'm now able to create a simple mobile app quiz using a low code, visual programming approach. The development process included component based design, block and event based programming, conditional logic, and procedural programming. The application was tested using an emulator and published as an Android application. The main goal of this project was to show how mobile applications can support learning, encourage participation, and provide learners with educational content that can be accessed anywhere.

Project Reflection

Although this project was optional, I have long wanted to learn the fundamentals of mobile app development. I assumed I would need to learn a traditional programming language, but the approach was quite different from what I anticipated.

For this project, I developed an interactive Classic Literature Quiz using MIT App Inventor. I designed the user interface using the same color palette and similar serif typography as my web-based quiz. Using block-based programming, I incorporated variables, procedures, conditional logic, and events to create ten multiple-choice questions with built-in feedback, automatic scoring, and a Play Again feature. I tested the application throughout the development process and conducted a final test before exporting and publishing it through GitHub.

I found MIT App Inventor relatively easy to learn and an excellent starting point for beginners. The drag-and-drop interface makes the development process less intimidating, especially for those without previous coding experience. However, successful app development still requires an understanding of the design components and Built In functions, as well as experimentation, testing, and troubleshooting. There were a few occasions when I had to revise the sequence of programming blocks for the application to function as I desired. This experience has increased my understanding of programming logic and the role of event-driven programming in mobile app development.

In the future, I would like to create a more complex mobile application that goes beyond ten simple questions and helps learners prepare for a rigourous assessment. I would also like to explore other approaches to mobile app development, strengthen my web-based programming skills, and learn more about user interface design principles. One limitation I encountered was that my published Android application was not compatible with iOS devices. I hope to develop applications that can accommodate learners using different devices and operating systems. I can see the potential for incorporating mobile applications into instructional design to create engaging, accessible, and flexible learning experiences.
