Mobile App Development

DESIGN • CONNECT • ENGAGE

This section showcases my dive into mobile app development and how it can be used as a tool for creating engaging, interactive learning experience. The purpose of this project is to show how these platforms can support learning, encourage participation, and provide learners with educational content that can be accessed anywhere.

Classic Literature Quiz

Welcome Screen

Quiz Screen

Results Screen

The Classic Literature Quiz is an interactive educational mobile application developed using MIT App Inventor. The application engages learners through ten multiple-choice questions with immediate feedback and automatic score tracking.

The visual design uses the same vintage literary color palette, serif typography, and literary imagery to create a cohesive and engaging learning experience.
