Screencasting

CAPTURE • DEMONSTRATE • EMPOWER

This project showcases using screencasting as a tool for teaching, guiding, and supporting learners. By combining screen capture, narration, zoom effects, and transitions, this project demonstrates how digital media can make learning more accessible, engaging, and effective while helping learners navigate tasks with confidence..

Screencasting Step-by-Step Tutorial

A screencast created with ScreenPal that provides viewers with a just-in-time tutorial on how to create and customize a column chart in Microsoft Excel. Through the use of zooming, highlighting, and transition effects, learners can easily follow each step of the process to gain a clear understanding.

Screencast Guide on using Google Vids

This screencast provides a walkthrough of Google Vids, an AI-assisted tool, for creating short educational videos. The demonstration shows the platform's main features using highlighting techniques to draw attention to key tools and functions used in creating learning content.
